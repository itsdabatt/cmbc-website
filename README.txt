UPLOAD TO GITHUB
1. Extract this ZIP.
2. Open the cmbc-website repository on GitHub.
3. Click Add file > Upload files.
4. Upload index.html, style.css, and the images folder contents.
5. Commit the changes.
6. Cloudflare Pages will update automatically, usually within 1–2 minutes.
7. Refresh the website with Ctrl + F5.

GOOGLE CALENDAR SETUP
The website uses this calendar:
campbellmemorialbyf@gmail.com

For visitors to see it, make the calendar public:
1. Open Google Calendar on a computer.
2. On the left, find the calendar under My calendars.
3. Hover over the calendar and click the three dots.
4. Click Settings and sharing.
5. Scroll to Access permissions for events.
6. Turn on Make available to public.
7. Choose See all event details if you want event names and details visible.

IMPORTANT: Only place public church events on a public calendar. Do not put private member details, counseling appointments, or confidential information on it.

PRAYER REQUEST FORM SETUP
The form sends requests to:
campbellmemorialbyf@gmail.com

It uses FormSubmit, a third-party form delivery service.
1. Upload and publish the website.
2. Submit one test prayer request.
3. Check campbellmemorialbyf@gmail.com for an activation email from FormSubmit.
4. Click the activation link.
5. Submit another test request to confirm it works.

Do not publish prayer requests publicly without the submitter's clear permission.

EDITING ANNOUNCEMENTS
1. Open index.html in GitHub.
2. Search for: Church Announcements
3. Edit the text inside the announcement-card sections.
4. Commit changes.
