UPLOAD TO GITHUB:
1. Open the cmbc-website repository.
2. Click Add file > Upload files.
3. Upload ALL files from this folder directly to the main repository:
   index.html
   logo.png
   church1.jpg
   vbs-register.png
   august-calendar.jpg
4. Allow index.html to replace the old version.
5. Click Commit changes.
6. Wait 1–2 minutes for Cloudflare.
7. Open https://cmbc-website.pages.dev and press Ctrl+F5 on computer, or close/reopen the tab on phone.

HOW TO VERIFY THE NEW VERSION:
- Immediately under the gold bar you will see a black/navy moving strip labeled “CMBC LIVE •”.
- Bottom-right will show “Tap for Sounds”.
